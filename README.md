Student Management System
The program stores student information so that they are easily accessable when in need
To compile: gcc ballzwise.c -o ballzwise
To run: ballzwise
Features Implemented:
1. It allows you to add the details of the student for example there name and age
2. it allows u to view the details of all the students that have been stored
3. The database of the student can be updated, deleted and a specific student detail can be sourced
